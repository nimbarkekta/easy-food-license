# Easy Food License

FSSAI food licence service: website, QR/link page and Android app.

- `index.html` – the website (English / Gujarati / Hindi)
- `qr.html` – links and QR codes for Instagram, Facebook, posters and WhatsApp
- `android/` – Android app. GitHub Actions copies `index.html` into the app and builds the APK on every change.

Documents are stored in the owner's Google Drive through a Google Apps Script backend (not in this repository).
